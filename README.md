# FUTURE_PE_02 - AI Content Marketing Using UGC Ads

## Project Overview

This project was completed as part of the Prompt Engineering Internship at Future Interns.

The objective of this project is to create a structured prompt system that generates authentic User Generated Content (UGC) style advertisements for local businesses.

The generated content includes:

* Multiple hooks
* UGC ad scripts
* CTA variations
* Prompt analysis

The content is designed to be suitable for Instagram Reels, Shorts, and social media advertisements.
